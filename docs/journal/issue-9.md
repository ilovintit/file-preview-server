# Issue #9：v1.0.0 完整重构与存储兼容

> 历史记录：标准 S3 兼容范围与应用层 AES 加密均已由 Issue #11 更新；本记录仅保留完整重构裁决。

## 稳定结论

- 用户裁决：不保留任何历史 HTTP 兼容设计；v1 仅保留 HTTPS/mTLS 上签名且防重放的内部 API 与公开 `GET /v/{token}` 导航入口。
- 所有内部调用使用 HMAC-SHA256 规范请求签名、300 秒时间窗、nonce 和双 key 轮换；静态 Bearer 与应用层 AES 信封设计退役。
- 对象存储经抽象适配：阿里云 OSS 是首个验收实现，标准 S3 API 是兼容路径；不把 silo 或任何供应商写死。
- 内容 SHA-256 是缓存与锁身份，token 签发请求必须带 `cache_ttl`，同内容并发等待首个转换完成；支持矩阵固定到 Gotenberg 8.34.0，并由 CI 逐项验证。
