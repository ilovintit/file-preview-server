# 客户端与调用方边界

本仓库不包含浏览器、PC 或移动端应用。它只提供 HTTP 服务，客户端归属如下：

- API server：以内部 Bearer 密钥签发预览 token；它是唯一可以提交资源 URL 的调用方。
- 管理后台服务：以不同的 Admin Bearer 密钥读取或撤销 token。
- 调用方前端：接收 `/v/{token}`；图片使用浏览器图片渲染，PDF/Office 由调用方统一的 PDF 组件呈现。
- 最终用户浏览器：只跟随预览重定向，不能取得内部/管理凭据。

`/preview/preview` 路径错误、调用方切换至 `/v/{token}` 以及 B 端免登详情补字段均不属于本仓库交付；它们需要在 `xlzb-project` 中单独排期。该边界对应 PRD 的非目标，不能通过本服务的兼容路由悄悄扩大范围。
