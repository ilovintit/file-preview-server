# H5 / PC Web 接入示例与测试环境

首版交付一套适配手机和桌面浏览器的阅读页及最小附件示例，供业务系统接入。范围依据 [#36](https://git.shw.top/shw-project/file-preview-server/issues/36) 和 [PRD](../prd/product.md)。小程序工程取消，真实业务部署不作为本项目验收前置。

## 项目内交付

目标目录为 `demo/preview-h5/`（Web 附件示例与共享阅读页）和 `demo/fixtures/`（仅允许格式的真实文件、sha256、来源与内容预期）。#25 交付实际页面、最小测试适配层和 Web 自动化；#26 交付可运行镜像、部署配置与业务接入说明。当前静态原型不代表这些运行产物已实现。

测试适配层仅接受仓库 fixture ID，执行测试访问控制与固定映射，持有测试 Internal key 并真实调用签发 API，返回 `{token, filename, preview_type, expires_at}`。生产 server 不注册 fixture/测试辅助路由。Web 页面不取得源 URL 或 Internal/Admin key，业务系统自行完成生产附件权限判断。

## 页面职责

附件示例按 ID 取最新详情，展示等待、取消、防重与失败重试，不透传列表行。共享阅读页读取 fragment 后立即清除，只从 token URL 加载内容，提供图片缩放、PDF 翻页/缩放、转换等待、取消/返回、失效与临时故障重试。

迟到 DTO/渲染结果不能覆盖新状态；离开清除内存展示信息，浏览器恢复缓存页按客户端契约失效。原型的审查场景/宽度切换控件不进入真实用户流程；模拟计时器不表示服务具有进度 API。

## 自动化与证据

CI 启动实际服务、Valkey、固定转换器与 OSS/silo 测试 profile，以固定 Chromium 验证 320/390 px 和桌面视口。覆盖允许格式的图片/PDF/办公文件、fragment、错误恢复、CORS/Range 与页面生命周期，不包含取消格式正向矩阵或小程序构建。

逐格式/provider 证据归 #37，页面旅程归 #25，实际镜像启动后的完整链路与接入包归 #26。mock 仅用于适用失败分支，不替代真实转换、存储或内容呈现。fixture、配置与报告均在本仓库，不含生产文件或凭据，不依赖其他业务仓库。

原型见 [design index](../design/index.html)。原型/DOM、真实 Web 自动化、镜像、实际部署分别记录事实。用户已取消人工真实验收与固定生产观察前置；业务使用后按既定格式范围收集 Bug，其他文件格式永久不列为后续需求。
