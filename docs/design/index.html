交互入口索引

仓库内 demo 本仓库是完全重构的 HTTP 文件预览服务；截至 2026-09-05，生产调用方 UI 不属于服务代码，但 v1.0.0 在本仓库维护微信小程序、H5 与 fixture demo，作为可点击和真机验收入口。原生 App 不在本期支持范围。

跨入口旅程

  1. API server 在 HTTPS 上以已轮换调用方密钥签名调用 POST /internal/tokens，提交 HTTPS 源 URL、缓存 profile、内容 hash、文件名和双 TTL，取得 token。
  2. 浏览器调用方保存并传给展示层的始终是 /v/{token}，而不是对象存储的签名目标 URL。
  3. 仓库内微信小程序 demo 用户点击 fixture 附件后，小程序只以附件 ID 调用 demo 详情/预览 API；该接口返回 token、文件名、展示类型和过期时间，绝不返回裸资源 URL。
  4. 小程序 demo 打开本仓库 H5 的 web-view；展示信息置于 H5 URL fragment，H5 读取后清除 fragment。
  5. H5 图片元素或 PDF 阅读器加载 /v/{token}；最终对象存储域名须满足 CORS/Range 条件。
  6. 服务验证 token，以内容 hash 查缓存；未命中时等待或转换后重定向到对象存储的短时签名 URL。被撤销或过期的 token 返回 404，H5 提示用户回到业务页面重新获取预览。
  7. 管理后台服务通过独立 Admin role 的 HTTPS、签名、防重放调用列出或撤销 token。

边界

本仓库的 demo/wechat-miniprogram/、demo/preview-h5/ 与 demo/fixtures/ 共同构成 v1.0.0 验收环境；它们须配置 H5、预览服务与实际对象存储域名，并在开发者工具和真机完成验收。阿里云 OSS 与 silo 是本期仅有的 storage profile。原生 App 的 WebView/下载查看器验证延后到下一版本；不创建或依赖外部仓库实现。

业务规则以 唯一 PRD 为准，接口细节以 API 架构文档 为准。
