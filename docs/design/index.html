交互入口索引

无仓库内 UI 本仓库是 HTTP 文件预览服务；截至 2026-09-04，dev 中没有前端入口或可点击页面，因此没有可创建或验收的本仓库高保真原型。调用方自己的浏览器、H5、WebView、小程序或 App 页面负责选择预览容器。

跨入口旅程

  1. API server 以内部 Bearer 密钥调用 POST /internal/tokens，取得 token。
  2. 调用方保存并传给展示层的始终是 /v/{token}，而不是对象存储的签名目标 URL。
  3. 浏览器图片元素可直接使用该地址；浏览器 PDF 以 iframe/object 等导航型容器展示，或由满足 CORS 条件的 PDF 阅读器加载。
  4. 小程序与 App 优先在自己的 H5/WebView 中复用上述浏览器路径；若采用原生下载和本地查看器，调用方先完成该 SDK 的 302、最终对象域名和文件打开验证。
  5. 最终用户访问该地址，服务验证 token 并重定向到原文件或转换后的 PDF；被撤销或过期的 token 返回 404。
  6. 管理后台服务通过独立 Admin Bearer 密钥列出或撤销 token。

边界

调用方前端的页面原型属于各自仓库。本服务不把调用方 UI 或 H5 预览页复制到此处；调用方须配置预览服务与最终对象存储域名，并按其所选容器完成接入验收。已知路径迁移和免登数据缺口不是本仓库 Issue #1 的范围，需在 xlzb-project 单独建 Issue。

业务规则以 唯一 PRD 为准，接口细节以 API 架构文档 为准。
