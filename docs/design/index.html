入口、角色与验收边界

入口 / 角色页面与动作当前验收状态
H5 / 浏览器预览用户图片 / PDF 阅读 → 错误恢复；宽窄屏既有交互参考；实际 Web 阅读待 #25
Internal API 调用方签发 token；HTTPS HMAC 服务端调用无独立界面，见 API 契约
Admin API 调用方列出 / 撤销 token；独立角色服务端调用无本仓库管理 UI，撤销后与失效同屏

只读阅读无提交或删除行为，无需虚构确认弹窗。取消在途等待直接返回；撤销属于 Admin API，原型仅模拟其用户可见结果。

设计依据、产品裁决与实现边界

业务真相见 唯一 PRD，技术支撑见 客户端契约、仓库内 demo 与 API 契约。

三项契约已确认：所有文件校验后受控存储、profile 内去重、cache_ttl ≥ ttl。当前范围由 #36 修正：仅常见图片、PDF 与微软/WPS 办公文件，其他格式永久不支持。#37 收紧格式，#25 实际 Web 阅读，#26 镜像与部署交付。原型为模拟参考，不代表实际服务或镜像已完成。
