入口、角色与验收边界

入口 / 角色页面与动作当前验收状态
微信小程序 demo 用户附件列表 → 获取预览 → H5；重试、取消、返回用户已确认入口交互通过
H5 / 浏览器预览用户图片 / PDF 阅读 → 错误恢复；宽窄屏用户已确认入口交互通过
Internal API 调用方签发 token；HTTPS HMAC 服务端调用无独立界面，见 API 契约
Admin API 调用方列出 / 撤销 token；独立角色服务端调用无本仓库管理 UI，撤销后与失效同屏
原生 App下一版本再定义本期不适用

只读阅读无提交或删除行为，无需虚构确认弹窗。取消在途等待直接返回；撤销属于 Admin API，原型仅模拟其用户可见结果。

设计依据、产品裁决与实现边界

业务真相见 唯一 PRD，技术支撑见 客户端契约、仓库内 demo 与 API 契约。

三项契约已确认：所有文件校验后受控存储、profile 内去重、cache_ttl ≥ ttl。两个原型入口交互均已获用户确认；基线 CI 与合入状态见产品定义 PR。真实 H5、签名服务与 fixture 由交付 Issue 完成；v1.0.0 以 H5 自动化验收，不以微信开发者工具或真机人工验收作前置，真实反馈来自交付后业务使用。
