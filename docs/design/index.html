交互入口索引

无仓库内 UI 本仓库是 HTTP 文件预览服务；截至 2026-09-05，dev 中没有前端入口或可点击页面，因此没有可创建或验收的本仓库高保真原型。v1.0.0 的微信小程序由调用方自有 H5 预览页承载；原生 App 不在本期支持范围。

跨入口旅程

  1. API server 以内部 Bearer 密钥调用 POST /internal/tokens，取得 token。
  2. 浏览器调用方保存并传给展示层的始终是 /v/{token}，而不是对象存储的签名目标 URL。
  3. 微信小程序用户点击附件后，小程序只以附件 ID 调用其业务详情/预览接口；该接口返回 token、文件名、展示类型和过期时间，绝不返回裸资源 URL。
  4. 小程序打开调用方自有 HTTPS H5 的 web-view；展示信息置于 H5 URL fragment，H5 读取后清除 fragment。
  5. H5 图片元素加载 /v/{token}；PDF/Office 由 H5 PDF 阅读器加载同一地址，最终 silo 域名须满足 CORS/Range 条件。
  6. 服务验证 token 并重定向到原图片、PDF 或转换后的 PDF；被撤销或过期的 token 返回 404，H5 提示用户回到业务页面重新获取预览。
  7. 管理后台服务通过独立 Admin Bearer 密钥列出或撤销 token。

边界

调用方前端的页面原型属于各自仓库。本服务不把调用方 UI 或 H5 预览页复制到此处；微信小程序调用方须配置 H5、预览服务与最终对象存储域名，并在开发者工具和真机完成接入验收。原生 App 的 WebView/下载查看器验证延后到下一版本。小程序所需的详情/预览接口、文件名与展示类型字段属于 xlzb-project 的独立 v1.0.0 交付项。

业务规则以 唯一 PRD 为准，接口细节以 API 架构文档 为准。
