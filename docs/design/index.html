交互入口索引

无仓库内 UI 本仓库是 HTTP 文件预览服务；截至 2026-09-04，dev 中没有前端入口或可点击页面，因此没有可创建或验收的本仓库高保真原型。

跨入口旅程

  1. API server 以内部 Bearer 密钥调用 POST /internal/tokens，取得 token。
  2. 调用方的页面把 /v/{token} 用作预览地址；图片直接渲染，文档由调用方统一以 PDF 方式展示。
  3. 最终用户访问该地址，服务验证 token 并重定向到原文件或转换后的 PDF。
  4. 管理后台服务通过独立 Admin Bearer 密钥列出或撤销 token。

边界

调用方前端的页面原型属于各自仓库。本服务不把调用方 UI 复制到此处；其已知路径迁移和免登数据缺口仍是 Issue #1 的跨仓库后续事项。

业务规则以 唯一 PRD 为准，接口细节以 API 架构文档 为准。
